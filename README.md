# AWS GenAI Pro — offline course

Works with no internet. Open `index.html` in Chrome, Safari or Firefox (double-click it).
Before the flight, copy the whole folder (not only `index.html`) to the laptop you will use.

- 🌐 button (top right): switch English / עברית. ☾ / ☀: dark or light.
- Progress is saved in that browser, on that computer. Same browser = your progress is there.
- Order: modules 0 → 15, then **Final exam** (80% unlocks the certificate). **Practice** repeats the questions you got wrong.
- Dotted words are jargon: click for the meaning. All terms + flashcards: **Glossary**.

Facts checked against AWS docs on 2026-11-13. Console screens are rebuilt copies, not real screenshots.
Terminal commands are real; the printed output is a short illustration.

For editing: `content/mNN.js` = one module, `content/exam.js` = exam questions.
Check after editing: `node tools/validate.js`.
